# Hotel-Finding-and-Adding

HOW TO RUN PROJECT

##

```bash

npm install
node app.js
```

have to make .env and in it have to initialize keys and their values like of 
1. ATLASDB_URL="mongodb_url"
2. CLOUD_API_KEY="get in the cloud"
3. CLOUD_API_SECRET="get in the cloud"
4. CLOUD_NAME="name we get in the cloud"
5. MAP_TOKEN="token to initialize map"
6. SECRET="something only user will know"
